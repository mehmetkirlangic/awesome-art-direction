## Latest Updates

### November 2026
- [Crystal Ski rebrands with Landor around a snowflake-shaped "y"](https://designcompass.org/en/2026/11/18/crystal-ski-landor-rebrand/) - The ski travel brand's new identity turns a split letter in its wordmark into a snowflake lens.
- [Proof of Words releases PoW Dumbria](https://designcompass.org/en/2026/11/17/dumbria-wood-type/) - A display typeface by Reymund Schröder reviving the concave stroke ends of 19th-century wood type.
- [Unslop cleans up color, spacing and fonts on AI-generated screens](https://designcompass.org/en/2026/11/17/unslop-ai-ui-redesign/) - A Claude Code skill by Damir Sokolovsky that audits and fixes generic-looking AI web UIs.
- [Singapore refreshes its national brand around a glowing red sphere](https://designcompass.org/en/2026/11/17/singapore-brand-identity-refresh/) - The "little red dot" grows into a luminous sphere, carried by red gradients and light-and-shadow motion across campaigns.
- [LottieFiles launches Lottie AI for text-to-animation](https://designcompass.org/en/2026/11/16/lottie-ai-editable-vector-animation/) - Describe a movement in words and get an editable Lottie vector animation for loaders, icons or onboarding.
- [Google redesigns the Phone by Google app icon](https://designcompass.org/en/2026/11/17/google-phone-gradient-icon-redesign/) - A bigger handset glyph and a blue gradient lead a refresh of Phone, Messages and Contacts icons.
- [Caixa unveils its first logo refresh in nearly 30 years](https://www.creativebloq.com/news/this-banks-vibrant-new-logo-design-ticks-all-the-boxes) - Brazilian agency Tátil brightens the state bank's colours with a lowercase wordmark and a refined X.
- [Figma adds AI object selection and editable vector illustrations](https://designcompass.org/en/2026/11/10/figma-ai-object-selection-vector-illustration-editing/) - One-click object selection for images, plus agent-made icons that split into editable layers.
- [Commercial Type releases Schenk](https://typecache.com/news/7167/) - A new type family from Commercial Type, logged on the Typecache foundry release tracker.
- [Figma Config 2026 recap](https://dev.classmethod.jp/en/articles/figma-config-2026-recap/) - Figma Motion, generative plugins, shaders, Weave tools and the Figma agent, with Code Layers coming soon.
- [Figma Motion launch](https://alternativeto.net/news/2026/6/figma-launches-a-new-integrated-motion-design-tool-alongside-code-layers-and-new-ai-features/) - Timeline animation built into Figma.
- [Framer 3.0](https://alternativeto.net/news/2026/6/framer-3-0-launches-ai-agents-branching-external-agents-and-a-redesigned-community/) - AI agents, branching and a redesigned community.
- [Figma release notes](https://www.figma.com/release-notes/) - Every new Figma, Make and Sites feature in one place.
- [Framer updates](https://www.framer.com/updates) - Monthly Framer feature updates.
